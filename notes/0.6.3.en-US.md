# Pure Tokens Switch 0.6.3

Adds a local AI Drama workspace and improves client setup, model discovery, and usage history. Projects, drafts, and creative assets stay on your device; model requests and billing continue through Pure Tokens services.

## Upgrading

- The release repository has moved. If version 0.4.0 cannot check for updates, download this version from the official website and install it over the existing application.
- Existing projects, saved model choices, and task records are retained. Upgrading does not automatically resubmit generation requests.

## Client configuration

- Windows detection supports Claude Desktop MSIX and traditional EXE installations. Claude Desktop configuration uses its supported default-model format while preserving other settings and recovery.
- Configuration checks each client's installation identity and capabilities. TRAE setup explains save-work impact before a restart and retains recoverable state when host operations fail.
- New and regenerated API key names include the device, client, and Switch version, such as `win-chatgpt-v0.6.3`.
- The default-model area suggests trying a US or Japan node; actual speed depends on the network. Navigation remains accessible in narrow windows.
- Official Skills guidance includes an install-or-update prompt; one-click model configuration does not require Skills. OpenMausBot setup configures chat models without changing media settings; the default package does not include the paused MCP executable or require Go.

## AI Drama

- Create in a separate desktop workspace with local projects for stories, scripts, shots, and assets. Generate images, video, speech, and music, then compose and export on your device.
- Browse 15 visual styles with consistent 16:9 examples, categories, search, and previews. Example subjects are not added to generation requests.
- Manage models, groups, and generation options in one place. When no video model is saved, a compatible Seedance model available to the account is preferred; saved choices and running tasks remain unchanged.
- Text tasks run directly. Image, video, and audio requests ask for cost confirmation in the conversation, then continue the original task. The task center keeps submitted work in sync across page changes and project reopening without resubmitting or charging again.
- Fixes include stale model labels, completed reference images left marked as generating, video-erasure previews that would not open, media previews that failed after closing, and a possible blank AI Drama window on Windows. Canvas nodes remain selected after dragging.
- Required creation tools are checked before use and can be downloaded into Switch's local tools folder with one click, without administrator access or a separate package manager. Downloads support the system proxy, progress, errors, and retry; installation may take about 15 minutes to 2 hours depending on the network. Ordinary image and sketch editing remain available; 3D creation is not included.

## Model plaza and usage history

- CNY price display uses a fixed 0.35 coefficient. Prices show up to six decimal places, and per-1K-character quotes are converted once. The DeepSeek official CNY price example in the multiplier guide uses 0.25; display rules do not change billing or account balances.
- Model status follows the Web presentation of latency, throughput, and success rate, distinguishing empty samples from unavailable measurements. Reviewed StepFun transcription and ElevenLabs audio models have gateway API examples; unreviewed models do not receive guessed chat examples.
- Fixes missing card prices for linear generation-plus-reference-video quotes. Cards show per-second generation rates for up to three resolutions; details retain all specifications and reference-video fees. Actual billing is unchanged.
- Provider artwork and offline fallbacks are consistent, while model-specific artwork is retained. Text and general models no longer repeat the multimodal label.
- Usage history aligns its filters, model and group search, streaming speed, Fast, and reasoning indicators with the Web client. Client icons appear before timestamps; request details show recorded request paths and protocol conversions. Historical fees are not recalculated.
- Usage display and filters read API key names without automatically retrieving full keys. Name-loading failures can be retried independently and show an allowlisted diagnostic code.
- The sign-in background and supported-client layout have been updated, with clearer text contrast and improved window restoration.

## Installation and availability

- macOS packages are not Apple-notarized, and Windows packages are not Authenticode-signed. System warnings about an unknown developer or publisher may appear. Updater artifacts still use Tauri signatures for integrity verification.
- Model availability and task results depend on the account and supporting services. Successful configuration does not establish live-call acceptance for every host version and model combination.
