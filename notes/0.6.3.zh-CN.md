# Pure Tokens Switch 0.6.3

新增本机 AI 漫剧工作区，并完善客户端配置、模型广场和使用记录。项目、原稿与创作素材保存在用户本机；模型请求和计费仍由 Pure Tokens 服务处理。

## 从旧版升级

- GitHub 发行仓库已迁移。如 0.4.0 无法检查更新，请从官网下载本版并覆盖安装。
- 升级保留已有项目、模型选择及任务记录，不会自动重新提交生成任务。

## 客户端配置

- Windows 支持检测 Claude Desktop MSIX 和传统 EXE 安装。Claude Desktop 改用宿主支持的默认模型格式，同时保留其他设置和恢复机制。
- 配置前检查客户端实际安装身份与能力。TRAE 重启前提示保存工作，宿主操作失败时保留可恢复状态。
- 新建或重新生成的 API Key 名称包含设备、客户端和 Switch 版本，例如 `win-chatgpt-v0.6.3`。
- 默认模型旁提示可尝试美国或日本节点；实际速度因网络环境而异。窄窗口操作栏保持入口可点击。
- Skills 引导提供安装或更新提示词；一键配置模型不要求预先安装 Skills。OpenMausBot 只配置聊天模型，保留已有媒体设置；默认安装包不包含暂停的 MCP 程序，也不要求 Go。

## AI 漫剧

- 在独立桌面工作区管理本机项目、故事原稿、剧本、镜头和素材，生成图片、视频、配音与音乐，并在本机合成和导出。
- 提供 15 种画面风格及统一的 16:9 示例，支持分类、搜索和预览；示例题材不会加入生成请求。
- 在统一设置中管理模型、分组和生成参数。未保存视频模型时优先选择账户内可用且兼容的 Seedance；已保存选择和进行中的任务不变。
- 文本任务直接执行；图片、视频和音频在对话中确认费用后继续原任务。任务中心在切换页面或重开项目后同步已提交任务，不重复提交或计费。
- 修复过期模型名称、人物参考图完成后仍显示生成中、视频擦除无法预览、媒体预览关闭后失效，以及 Windows 打开独立漫剧窗口可能白屏的问题。画布节点拖动后保留选中状态。
- 使用前检查所需工具，缺失时可一键下载安装到 Switch 本机工具目录，无需管理员权限或先安装包管理器。下载支持系统代理，提供进度、错误与重试；根据网络状态约需 15 分钟至 2 小时。普通图片和草图编辑保持可用，本版不开放 3D 创作。

## 模型广场与使用记录

- 人民币报价展示使用固定系数 0.35；价格最多显示六位小数，每千字符报价只换算一次。倍率指引中的 DeepSeek 官方 CNY 价格示例使用 0.25；展示规则不改变账单或账户余额。
- 模型状态按 Web 口径显示延迟、吞吐和成功率，区分无样本与指标不可用。已审核的 StepFun 语音识别及 ElevenLabs 语音模型提供网关调用示例；未审核型号不展示猜测的聊天示例。
- 修复含生成费和参考视频费的线性动态报价在卡片缺失的问题：卡片展示最多三个分辨率的每秒生成单价，详情保留全部规格及参考视频费用，不改变实际计费。
- 统一供应商图标与离线回退，保留模型专属图标；文本及普通模型不再重复标注“多模态”。
- 使用记录对齐 Web 的筛选、模型与分组搜索、流式速度、Fast 和推理标识。客户端图标放在时间前，请求详情展示已记录的请求路径与转换协议；历史费用不重新计算。
- 使用记录展示与筛选只读取 API Key 名称，不自动获取完整密钥；名称加载失败可独立重试，并显示脱敏诊断码。
- 更新登录页背景、文字对比度及支持客户端布局，并改善窗口恢复行为。

## 安装与使用边界

- macOS 安装包未做 Apple 公证，Windows 安装包未做 Authenticode 签名，系统可能显示未知开发者或发布者提示；更新产物仍使用 Tauri 签名验证完整性。
- 模型可用性和任务结果取决于账户及配套服务。配置成功不代表所有宿主版本与模型组合均已通过真实调用验收。
