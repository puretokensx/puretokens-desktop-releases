Include Wan reference and output duration in quotes, and label reservation limits for unmeasured references or adaptive duration. ## Upgrade and usage notes

- This release is 0.7.0. Existing 0.6.3 tags, installers and notes recorded by those tags remain unchanged. Projects, model choices, conversations and tasks follow supported migrations; older clients must not open newer data by lowering the database version marker.
- This version requires matching Native, Renderer, BFF, New API and relevant Console/Web verification pages. Updating one component does not establish delivery across all surfaces. Request success depends on the account, model capabilities and service state.
- Compatibility depends on the host version and configuration. Follow the scope shown for Antigravity CLI, Claude mapping and new Skills paths; general installer acceptance does not imply every host and paid-model combination has been tested.
- Community macOS installers are not Apple-notarized and community Windows installers are not Authenticode-signed. Public updates still require Tauri signature and same-byte publication verification.
