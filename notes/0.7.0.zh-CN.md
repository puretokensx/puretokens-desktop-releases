# Pure Tokens Switch 0.7.0

补齐万相参考视频与输出合计费用；未知参考时长、自适应时长显示预扣上限。可灵、批量和助手确认同步展示预扣语义，模型广场补齐参考最低时长、合计取整及免费图片说明。使用记录可通过配套服务恢复原图片任务的迟到成品，不重复提交。升级至 0.7.0 后使用，相关能力取决于配套 Web 服务、账号与模型支持。

本次更新完善 Kimi Code、MiniMax Code 与 Oh My Pi 接入，新增 Antigravity CLI 和 Claude Desktop 兼容模型配置，并改进对话驱动漫剧制作、企业钱包、兑换和通知。企业共享计费尚未启用，本次客户端发布不改变服务端企业计费开关。


## 客户端凭据兼容与使用记录

- 修复 Claude Desktop 已存凭据字符串较长时误报供应商归属冲突的问题；新输入 Key 校验、配置归属检查和原字节恢复保护保持。
- 修复 WorkBuddy 重新应用产生重复模型，以及 Hermes、Kimi Code、MiniMax Code、EvoX、Oh My Pi 的受管旧凭据阻止重新配置的问题；完善 Claude Code、Gemini CLI、DSH Desktop 的受管字段恢复，保留个人配置与未知条目。
- 使用记录的 fast 加速说明文字改为与 Web 一致的绿色，保留原文案和金色 fast 标识。

## 创作能力同步 Web

修正免费参考图、参考视频时长取整、按请求与 Kling 条件报价，让确认金额跟随实际选项。图片编辑遵守分辨率和参考数量限制；视频支持目录声明的自适应时长、动作控制、默认参数及素材规则，未知费用继续明确显示。

接入已支持的 Lyria 音乐，按模型提供朗读说明、双说话人和温度。高级参数随任务保存，旧任务按原 ID 核对；固定共享画布助手配音仍使用默认参数。关闭视频延长新建入口，保留历史与成品。生成能力取决于配套服务、账号权限和模型支持。

## 模型广场同步 Web

标题新增 `$1=¥0.25` 标识，倍率说明移到帮助区。视频报价清楚区分静音、生成声音、保留原声等场景，切换币种或价格组保留当前选择；相同费用合并展示。调用示例补齐参考素材、首尾帧、视频编辑、语音对话、音乐和实时语音，并标明 Python/Bash；异步任务与直接音频返回分开说明。标题标识仅展示，不改变计费。

向量、重排、Decision 等普通请求模型在成功读取且无采样时，与 Web 一致展示 0.3s、99.00% 和 60 格绿色历史；hover 与无障碍标签明确标注“默认展示（非实测）”，不显示 Token 吞吐。已有实测仍保留真实耗时、失败、0% 及缺失指标；加载、刷新、读取失败或过期时不补默认值。原始样本及计费不变。

## 客户端接入

- 首次检测和主动重新检测显示全屏 loading，完成或失败立即退出，失败时保留可操作的恢复入口。顶部服务范围说明在加载期间也显示；分组气泡完整展示，窄窗口可换行，保留高亮与流光边框。返回页面保留已有内容、选择和步骤，后台刷新只用延迟轻量提示，配置操作仍等待本轮核验完成。
- 注意事项按客户端拆成编号操作步骤，用加粗动作标题和橙色“关键一步”突出重点；DSH 明确为重启 DSH Desktop、新建会话选择模型、发消息确认回复；重启前先保存工作并完全退出，未启动时直接打开。登录和初始化只在客户端要求时完成。模型验证提醒放在最后一步，配置保存状态仍位于“知道了”左侧。窄窗口正文可独立滚动，按钮持续可见。
- “使用条件”改名为“注意事项”，从配置页和写入确认框移除常驻说明；只有一键配置实际保存成功后，自动弹出对应客户端的注意事项。弹窗以编号步骤说明接下来的操作，突出关键动作并保留验证提醒，提供“知道了”关闭按钮，支持 Escape 和点击遮罩关闭。预检、取消、失败或重新进入已配置页面不弹出；关闭后不自动重现。客户端及桌面／CLI、Claude 映射模式绑定本次操作，不随异步期间的页面选择串换。写入前的必要授权告知和独立重启确认保持。
- 配置成功后的注意事项弹窗展示各客户端的账号、初始化、模型选择及 Switch 运行条件。保存成功只表示配置已保存；桌面重开和终端打开分别提示，不代表宿主已登录或模型调用已验证。
- 修正 Windows Claude Desktop 第三方配置目录，使用系统提供的 Local AppData 下 `Claude-3p`。升级后需重新应用配置；旧 Roaming 文件保留，不会自动搬迁或误报为已生效，macOS 路径不变。

- 分组选择行居中对齐，选择框新增“选择分组，一个客户端，调用不同模型。”橙色高亮气泡与流光边框，不占布局、不阻挡点击，多选标签仍可横向滚动；减少动态效果时保留静态高亮。
- 修复本地 API 请求被代理干扰，以及 Windows 会话路径写法不同导致恢复失败的问题；加强跨平台导出、抠图下载与构建前置检查。
- 修复本地 Claude 模型映射被系统代理干扰的问题，本机上游保持直连；公网连接继续使用原代理设置。
- 移除 ChatGPT/Codex 的 Fast、插件市场增强设置和增强启动。保存工作确认后统一普通重启；配置、模型、会话和恢复继续可用，已有原生偏好保持。
- Kimi Code 与 MiniMax Code 分别检测桌面端和命令行，显示各自安装状态、版本及启动入口。双端共享默认配置；MiniMax 桌面自定义目录与 CLI 不同时分别预览、写入和恢复。保留原有个人设置。
- 新增官方 Oh My Pi `omp` 命令行配置、两份 YAML 的事务写入、默认模型、恢复和终端启动。第三方桌面包装及会话管理不在本次范围。
- 新增 Antigravity CLI 配置。保持 Switch 登录运行，点击“启动 Pure Tokens 会话”，在新会话的 `/model` 中搜索 `Pure Tokens` 并选择模型；直接运行普通 `agy` 不会加载此连接。Key 仅传给新会话，不写入配置文件；所选分组必须包含辅助模型 `gemini-3.1-flash-lite-preview`。不配置 Antigravity 桌面端。
- Claude Desktop 可通过 Switch 管理的本地模型映射使用兼容的其他供应商模型。配置页区分“本地路由”与原生直连的“智能路由”；映射模式需要 Switch 登录并保持运行，退出或登出后停止。模型准入以当前服务声明的协议为准，不导入媒体专用或协议未知的模型。
- 桌面端、命令行与 Bot 分类按支持能力显示入口，未安装不会使受支持客户端消失；安装未知不会被当成已安装。Kimi Code、MiniMax Code、OpenCode 各端只显示对应版本与启动操作；桌面重启仍单独确认保存工作。
- 改善空 YAML、保留注释和换行的配置更新，以及 DeepSeek Harness、DS Bot、DSH、Hermes、EvoX 等受管配置缺失时的恢复。损坏文件、归属冲突与并发变更继续阻止不安全写入。登录不再后台覆盖 DS Bot 后来修改的配置。
- 配置错误显示失败阶段和原因，Key 读取采用有界批次，恢复过程保留原任务及必要凭据。VS Code 配置仍仅写受管文件，启动或重启是独立动作。
- Skills 引导依据具体客户端、连接模式及已有发布证据显示。Oh My Pi 与 MiniMax `mcode` 仍有独立 Skills 发布和真实宿主验收要求。Claude Desktop 映射聊天的本机令牌不能授权 Skills 专用接口；应用配置会在原确认中披露明文 Key，并同时准备同宿主的独立 Skills 连接。两仓兼容版本发布前保持“仅源码支持”，直连保留已有支持。登录只维护已确认的配置，额外或被修改的文件需重新应用；模型配置成功不代表媒体 Skills 已可用。

## 创作助手

- 新建多版本宫格在工具加载完成时及时居中，后续编辑或取消费用确认不会再触发迟到的画布位移。
- 明确要求制作漫剧后，助手可沿同一目标继续规划、准备人物和场景、制作镜头、生成配音并本机合成，减少每一步等待“继续”。画布与剧集共用项目素材，已选作品保持，替换按明确要求执行。
- 自动审批默认开启，可随时关闭，并按账号和项目记住选择；偏好读取或保存失败时关闭。只作用于助手当前提案，不扩展到人工生成区域，文件导出仍需确认。生成前仍检查模型、参数和费用；无法估价、费用变化、素材冲突或提交结果未知时会说明原因并暂停相关步骤。停止或重启后，不恢复旧任务的提交许可，也不自动重复计费。
- 创作要求贯穿画幅、分辨率、镜头时长、声音、字幕和合成。未保存视频默认模型时优先选择可用且兼容的 MiniMax-H3；用户已有选择和运行中任务保持原模型。视频时长跟随镜头要求，不再取列表第一项。
- 单个视频与剧集／画布成片接受目标时长 ±1 秒（含边界），整片容差不按镜头数累计；范围内保留实际时长，不因时长阻塞、不自动裁剪或重生成。实际尺寸、清晰度及内容仍独立检查，不支持的画幅不会静默改为方图。
- 修复已生成仍等待交付、停止后按钮仍显示执行中、暂时同步失败后无法继续和重复失败状态阻止收尾的问题。停止助手不取消或退款已提交的云端任务；恢复只核对原任务，不以新的生成请求替代。已完成媒体继续交付，异常结果可预览并显示“成片需检查”；只有与当前来源匹配且已保存的成片才能证明本次交付，模型声明或旧候选不能代替。
- 项目内可通过弹窗命名新对话，在历史弹窗中查看、切换、归档或删除。执行中仍可查看历史，切换及管理须等当前任务和待发送消息处理完毕。对话与草稿独立，项目素材、任务与扣费记录保留；有未完成工作时提供准确状态和恢复入口。标题直接显示“「对话名」创作助手”。
- 减少重复技能记录与过程提示，历史和新对话移入标题栏；模型图标、发送／重试／停止状态保持清晰，多媒体确认不再撑宽会话框。

- 创作助手支持按时间添加本机剧情音效，保留已有音乐；三次敲门等事件可以精确安排到时间线。

- 创作助手和时间线支持设置镜头原音、配音音量与配音起点，预览和合成保持一致；保留完整对白，更换素材后避免沿用过期起点。

- 修复助手视频请求未被服务端受理时反复待核对的问题；安全核对原请求，不重复生成。明确内部任务类型指引，减少模型格式错误。

- 改善创作助手选用已有素材的连续性：明确候选先后顺序，保留本轮已读镜头信息，减少反复查询。采用前仍核对当前选择。

- 修复助手生成后镜头视频参数回到目录首项的问题：没有手动设置时沿用同模型成功候选的时长、画幅和分辨率，保留用户明确设置。

## 剧集、素材和合成

- 任务中心先在本机按类型与状态筛选再分页，每页最多 200 项，分类计数覆盖完整项目，不再只筛选首页结果；进行中任务优先，闲置降低轮询频率，隐藏时暂停轮询。素材库深分页复用现有索引，不迁移数据库或删除任务。
- 画布、剧集制作、助手消息和媒体预览按需加载；已访问编辑区切换后保留草稿，代码加载失败可单独重试。漫剧入口 JS 从约 1.72 MB 降至 473 kB；这不代表安装包缩小相同比例或真实启动耗时已完成测量。
- 修复懒加载视频预览已读取媒体但进度条仍为零的问题：播放器挂载时同步已加载的时长和画面尺寸，保留后续媒体事件、画幅及字幕行为。

- 剧集总览展示封面、集数、简介及当前进度，按“准备内容 → 制作镜头 → 合成导出”组织下一步；已有剧本、镜头和成片可直接继续或查看。
- 镜头页先看画面，文案、对白、素材和候选历史按需展开。规划、批量制作、图片、视频和声音工具使用紧凑一致的布局，明确当前操作和生成费用。
- 人物、造型、场景与道具展示已有缩略图、生成状态和可采用候选；失败任务保留旧图。详情按图片、描述、造型和声音整理，可定位原任务或选用项目已有素材。
- 创作设置集中项目画面风格和账号默认模型，切换分类保持窗口尺寸；创作环境入口移到设置标题区。未保存修改、素材引用及草稿继续受保护。
- 关闭创作设置后，键盘焦点返回原入口。修复视频／抠图工具安装结束后仍可能误报“正在安装”，以及历史恢复结束后锁未及时释放的问题。
- 图片模板确认在空间不足时自动移入可用视口，保持确认操作可达；缓存图片可正常进入裁剪等处理，切换图片后旧加载结果不会覆盖当前图片状态。
- 任务中心按文本、图片、视频、音频和成片分类，单独筛选状态；长描述与编号按需展开。已停止、执行中、待核对和完成结果不再混淆。
- 合成导出突出最近完成成片，历史版本按需查看；镜头顺序、裁剪、声音、字幕、画幅及实际输出尺寸更清楚。预览与已保存成片分别标识，原素材和历史结果保留。
- 修复打开漫剧或核对任务时窗口无响应、迟到回复覆盖新结果，以及已完成候选未及时显示的问题。项目回收恢复、媒体导出与本机素材复用继续保留原内容和可恢复记录。

## 钱包、兑换和通知

- 企业仅作为付款钱包，沿用平台统一模型定价。分别展示个人余额、订阅与本人可用企业额度；离开企业后移除企业付款项，保留订阅及个人余额顺序，重新加入不恢复旧企业授权。
- 企业付款的调用和消费详情与其他付款方式一同进入使用记录，保留原始金额和 Token；未知历史字段不补造。需要配套网关、BFF 与客户端一起交付。
- Switch 支持活动兑换入口、安全验证、明确回执与原请求核对。企业邀请等需要确认的事项跳转对应 Web 页面，返回后刷新；Switch 不管理企业邀请。账本暂时不可用不再把旧兑换当成本次成功，零或负数到账回执不会显示成功。
- 充值资料加载失败时显示可重试状态，恢复不会自动兑换输入的代码。客服标题右侧同行、右对齐展示淡蓝色“企业接入”和紧凑暖色“新用户加群获取 $5”提示，工作时间放在标题下方；企业入口通过系统浏览器打开 Web 企业接入页面，不受账户余额影响。
- 顶部充值按钮增加“新用户赠$5”悬浮气泡，不占文档流或阻挡点击；与客服新用户提示共用零额度条件。只有确认没有个人、订阅或企业可用额度时才显示；正余额、无限额度、未知、加载或读取失败时隐藏。提示不自动发放额度，原有资格与领取流程保持。
- 账户消息可触发系统通知，并提供不改变余额的测试通知。分类开关、已读去重和首次加载保护保持有效；需要确认的企业事项去 Web，文本通知可在 Switch 查看，系统权限和专注模式仍由用户控制。

## 模型广场、使用记录和启动

- 失败记录使用红色状态、红色金额、浅红底色和左侧红色标记，与绿色退款入账记录对称。全额／部分／已有退款标签放在金额上方，时间栏只保留执行结果；列表去掉“任务实际支出”，始终展示本笔原始流水金额，不以退款后的净支出覆盖原扣款。原扣款、累计退款和净支出仍在详情查看，真实零值及未知保持。只有执行成功的媒体任务显示查看图片／视频入口，其余状态保留详情。本次仅调整 Switch 前端展示，不修改服务端、账务或 HTTP／IPC 契约。
- 登录背景、中英文分享海报与 ZCode 图标改为无损 WebP，保留原尺寸、像素及元数据，减少约 2.06 MB 随包图片；原始品牌素材和示例视频保持。

- 人民币报价展示系数统一为 0.25，动态价格使用当前分组及实际参数；展示换算不改写账单或余额。模型卡片与详情同步 Web 口径，区分无样本、加载失败和过期状态，保留缓存写入与全部规格说明。
- 使用记录将客户端图标、时间和状态放在同一行，移除分组列及分组筛选，保留模型、API Key、请求详情和其他筛选。已消耗的流式失败显示准确失败状态，已记录费用保持。
- 登录页“保持登录”默认勾选，可在登录前关闭。仅最小续登录凭证使用系统保护存储，Switch 不持久保存密码、访问 Cookie 或完整 Key；已确认的第三方配置写入按既有规则处理。无法静默保存时仍可普通登录，不要求电脑密码。
- 启动使用横向进度条和阶段提示，首屏准备后显示窗口，减少白屏；加载失败可重试并支持减少动态效果。登录后立即展示客户端列表，后台补齐安装及配置状态。
