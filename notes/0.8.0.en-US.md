# Pure Tokens Switch 0.8.0

Adds configuration and restore support for MiMo Coder, Qwen Code, CodeBuddy Code, GitHub Copilot CLI and Factory Droid, with installed-version detection and updated image pricing and audio API guidance.

## CLI clients

- Choose groups and compatible models, preview changes, then confirm configuration with backup and restore support. Personal providers and unrelated settings remain intact. Corrupt files, known overrides, ownership conflicts and concurrent changes continue to block unsafe writes.
- Qwen Code uses the selected default model. CodeBuddy Code, GitHub Copilot CLI and Factory Droid preserve existing defaults; select Pure Tokens in `/model` after configuration. Restart MiMo Coder and start a new session to read its user configuration. Project settings and launch arguments can override that default.
- Qwen Code permits unrelated home `.env` files that do not override its model settings. CodeBuddy Code supports existing array layouts and identifiable managed legacy models, avoiding duplicates when keys change.
- Factory Droid permits unrelated settings and confirmed legacy-model migrations. MiMo Coder allows unrelated preferences alongside model configuration and updates only one target file. Actual conflicts retain specific diagnostics.
- Read installed files to identify all five client versions without executing the clients. Unverifiable versions remain unknown. The client cards use their corresponding product icons.
- On macOS, MiMo Coder uses iTerm2 or the VS Code integrated terminal; system Terminal is not offered. These integrations do not include session management or establish real model-call acceptance.

## Model plaza

- Where capabilities are explicit, switch between text-to-image and image editing to see the total price per image, including reference-image costs. Details preserve the breakdown and explain that it must not be added again. Billing behavior is unchanged.
- Correct Google task-audio classification with older metadata and clarify asynchronous task polling, download after success, parameters and response formats. Retrieve the original task without submitting it again.

## Skills guidance

The five new clients show source-only support pending an official Skills release containing their adapters. Paseo guidance is limited to local Codex sessions using the same connection. Installation and invocation examples remain gated where release or session requirements are unmet. Switch does not install Skills or expand configuration permissions.

## Windows builds

The incremental updater supports the accepted 0.7.0 source as a baseline for 0.8.0, verifying the previous installer, new source and new build receipt separately. Existing compilation caches, dependencies, installers and logs remain intact. The new commit still runs the complete Windows native checks.

## Continuing usage guidance

- Windows Claude Desktop continues to use `Claude-3p` under Local AppData. Old Roaming files remain intact. Reapply configuration when migrating from that old path.
- “New users: join group for $5” and “New users get $5” appear only after confirming no available credit. Hints do not grant credit automatically or change eligibility and redemption. The task center retains type/status filtering and up to 200 items per page.
- Assistant approval applies only to current proposals, not manual generation controls; file export still requires confirmation. Each video and the complete episode or canvas output retain a tolerance of ±1 second, including the boundary, without blocking, automatically trimming or regenerating within that range.
- Stopping the assistant does not cancel or refund submitted cloud tasks. Recovery queries the original task; a model statement or older candidate is not completion evidence. Delivery requires saved output matching current sources. History stays readable while work runs; switching and management wait for current work and queued messages.
