# Pure Tokens Switch 0.8.0

新增 MiMo Coder、Qwen Code、CodeBuddy Code、GitHub Copilot CLI 和 Factory Droid 五个命令行客户端的一键配置与恢复，补齐安装版本识别，并同步模型广场的图片报价及音频调用说明。

## 命令行客户端

- 支持已安装客户端的分组和兼容模型选择、配置预览、确认写入、备份及恢复。保留个人供应商和无关设置；损坏配置、已知覆盖、归属冲突和并发修改仍会阻止不安全写入。
- Qwen Code 使用所选默认模型；CodeBuddy Code、GitHub Copilot CLI 和 Factory Droid 保留原有默认选择，配置完成后在 `/model` 选择 Pure Tokens。MiMo Coder 重新启动并新建会话后读取用户配置，项目设置和启动参数可能覆盖默认模型。
- Qwen Code 允许主目录存在不覆盖模型配置的无关 `.env`；CodeBuddy Code 兼容既有数组结构和可确认归属的受管旧模型，避免换 Key 时重复添加。
- Factory Droid 兼容无关设置文件及已确认迁移的旧模型；MiMo Coder 允许无关偏好与模型配置共存，只更新一个目标文件。真实冲突继续显示原因与处理提示。
- 通过只读安装文件识别五个客户端的版本；无法可靠识别时保持未知，不执行客户端来探测版本。补齐对应产品图标。
- macOS 上 MiMo Coder 使用 iTerm2 或 VS Code 集成终端，不提供系统 Terminal 启动选项。新增接入不包含会话管理，也不代表真实模型调用已验收。

## 模型广场

- 图片能力明确时可切换“文生图／图片编辑”，查看含参考图费用的单图总价；详情保留分项，并提示不要重复相加。显示变化不改变实际计费。
- 修正旧元数据下 Google 任务音频的分类，补齐异步音频任务查询、成功后下载、参数和返回格式说明；查询原任务，不重复提交。

## Skills 提示

五个新增客户端显示“仅源码支持”，等待包含相应适配的官方 Skills 版本。Paseo 提示限定本地 Codex 会话及同一连接；未满足发布或会话条件时不提供安装、调用示例。Switch 不因此安装 Skills 或扩展配置权限。

## Windows 构建

增量更新支持从已验收的 0.7.0 源码升级到 0.8.0，分别核对旧安装包、新源码和新构建回执。保留原有编译缓存、依赖、旧安装包及日志；跨版本更新仍执行新提交的完整 Windows 原生检查。

## 延续的使用说明

- Windows Claude Desktop 继续使用 Local AppData 下的 `Claude-3p`；旧 Roaming 文件保留，旧路径用户需重新应用配置。
- 充值页“新用户加群获取 $5”与“新用户赠$5”仅在确认无可用额度时显示；提示不自动发放额度，领取资格和流程保持。任务中心继续按类型与状态筛选，每页最多 200 项。
- 助手自动审批仅作用于当前提案，不扩展到人工生成区域，文件导出仍需确认。单个视频及剧集／画布成片继续接受目标时长 ±1 秒（含边界），范围内不因时长阻塞，不自动裁剪或重生成。
- 停止助手不取消或退款已提交的云端任务；恢复查询原任务，模型声明或旧候选不能代替与当前来源匹配、已保存的交付。执行中仍可查看历史，切换和管理等待当前任务及待发消息结束。
