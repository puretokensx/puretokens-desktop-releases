# Pure Tokens Switch 0.8.1

修正客户端版本识别与配置兼容性，同步模型广场、使用记录、账户和充值记录，并改进画布操作失败提示。

分组提示补充：使用图片、视频模型，请勾选对应供应商分组，安装 skill 后调用。提示采用亮浅橙底色与深棕文字，通过绝对定位伪元素与选择器留出间距，不额外占用布局空间。气泡提供可键盘操作的关闭按钮；关闭后同时移除气泡及选择器橙金流光／高亮边框，恢复普通边框，复用本机偏好记住选择，切换客户端、返回页面或重启后不再显示。关闭按钮同样绝对定位，关闭前后分组行均为正常 56px，不添加 padding、margin 或额外占位；辅助技术仍可读取分组说明。

## 兑换失败原因

- 兑换码过期、已绑定邀请人或邀请关系不符合要求时显示具体原因，不再统一显示“充值操作失败”。处理中保留原请求重试，人工核查继续阻止重复提交，未知错误不暴露内部诊断。

## 视频教程入口

配置确认页的「使用示例」标题旁新增「视频教程」按钮，点击在浏览器打开 Bilibili 教程主页。

## 系统通知设置

- 移除设置页的测试通知入口，保留正常通知开关与必要的授权说明。由系统管理权限时不再误提示未授权。

## 客户端版本识别

- 支持正式版本命令的 16 个 CLI 优先读取程序自身返回的版本；Grok 使用 version，其余使用 --version。查询失败仅使用同一安装的可信元数据，仍无法确认时显示版本未知。
- Hermes 分别显示桌面版本与“本机 Agent”版本。0.0.0 和空白不再显示为有效版本，不使用远端 backend 或另一份安装的版本替代；版本未知不影响正常配置。Codex 内嵌 CLI 使用自身版本，不借用桌面版本。
- 查询限制时间与输出，关闭标准输入，清理超时子进程并缓存结果。Windows 的 npm 入口经校验后直接通过 Node 执行，不经 shell。第三方版本命令仍可能执行其自己的更新检查。
- 纯桌面客户端继续读取对应应用的安装元数据。此次变更不扩大客户端配置写入、自动重启或账户凭据的权限。

## 画布操作

- 创建画布失败时明确提示名称、数量或当前账户问题，保留当前画布与输入，不自动重复创建。
- 删除失败时明确提示冲突、最后画布或待核对任务；未知错误隐藏内部存储细节。
- 整理画布创建、删除、历史操作和媒体编辑状态的内部职责，保留草稿、切换、保存和事务回滚行为。

## 客户端配置与检测

- Claude Desktop 密钥标签统一为“API Key”。本地映射模式的主按钮明确显示“配置并启用本地路由”，可用模型区不再显示独立的映射状态提示；直连的一键配置、安全确认与失败提示保持不变。

- Claude-3p 的缺省 bearer 鉴权及普通宿主偏好可保留，不因宿主新增普通设置误判归属冲突。Windows Claude Desktop 使用 Local AppData，不继续写入旧 Roaming 目录；升级后重新应用配置，旧目录保留，启动和模型调用仍需实际宿主验证。
- 多个客户端保留普通模型和提供商设置；真实地址、鉴权、协议冲突及会丢失个人设置的操作继续保护原文件。设置冲突与文件损坏分别提示，不静默删除偏好。
- 检测等待超时显示可重试状态，不判定未安装。局部重新检测不再使首次扫描中的其他客户端丢失；停止等待不代表后台阻塞探测已终止。

## 模型、使用记录与钱包

- 普通图片编辑与 JSON 遮罩编辑分别展示，不再互相覆盖；修正遮罩示例的 `image_urls` 数组格式。
- Skills／提示词及分类保持 Web 服务端顺序，切换分类不再意外重排导航。
- 已开票记录显示邮件进度。邮件服务接收不再被当成已送达；失败或结果待确认时提示工作人员核对，避免重复申请或付款。

- 充值记录去掉手动刷新：每次打开抽屉自动刷新一次，滚动到底部继续加载。失败保留已有记录，并可重试原页。
- 补齐发票记录，显示抬头、状态、最终票面金额、开票费及发票号码和时间。此入口只读，申请、付款与下载仍在 Web 完成。

- 会员有效期支持小时、月、年和自定义秒，不再因按月／年订单缺少天数而加载失败。历史会员权益保留，已退役激活码不再展示或复制；余额兑换码充值不受影响。
- 钱包部分刷新不再丢失已加载的奖励／调账通知；通知计数未知时显示“—”，不误报全部已读，切换账户清除旧展示。

- 余额记录中的兑换码入账统一标为“兑换码充值”，与在线充值共用分页；较早的兑换码记录可继续加载，保留到账额度、状态和参考号复制，不与会员激活混淆。

- 充值记录区分实付金额／币种与到账额度，未支付订单不再显示入账正号；支付方式使用支付宝／微信支付图标。会员记录补齐在线购买订单，保留历史兑换，支持独立分页和刷新。记录卡同步 Web 的时间／状态、标题／付款、右侧额度和会员有效期布局，去掉重复标签和空完成时间。用量超过前 100 页时提示缩小筛选范围。

- 媒体调用示例支持目录声明的 data URL 素材；详情显示已声明的输出尺寸、任务状态及只读查询示例，并提示异常核对和避免重复提交。缺失的能力和尺寸不再猜测，页面不会自动生成或轮询。
- 媒体价格隐藏未映射的兜底规格，附加费用说明仅对应可见价格；邀请统计改为“累计有效充值”，使用记录 max 推理强度使用独立样式。
- 模型详情分为调用示例、概览、价格三个页签；多档模型默认打开价格，切换保留分组、币种和 Token 单位。价格条件、规格及附加费与 Web 同步。
- 使用详情抽屉占桌面窗口的 50%，逐项展示历史计量、官方单价、小计与表尾结算总额；待结算预扣与消费分开，退款方向保留。账单时间优先使用记录中的历史时区，不以当前价格重算。
- 账户可用额度／订阅、会员及企业数据支持一次后台续读；失败保留同账户陈旧展示并标明状态，陈旧余额不用于兑换或赠额资格。企业额度未就绪或陈旧时，顶部和充值页不以旧零余额或旧未绑定状态显示赠额提示。
- 兑换统一使用钱包接口，会员历史仍可查看。购买额度与官网链接打开 Web 钱包；Switch 不创建在线支付订单。充值记录同步来源、支付方式、发生时间、取消／过期／未知状态及余额活动。
- 客服提示为“新用户加群获取 $5”，顶部使用“新用户赠$5”；仅在确认无可用额度时展示，不自动发放额度。任务中心每页最多 200 项，分类数量按全项目统计。

## 助手与创作边界

- 单个镜头及剧集／画布成片接受 ±1 秒（含边界）容差，范围内不因时长阻塞、不累计镜头容差、不自动重做；画幅、内容与质量核验保留。
- 自动审批仅适用于已声明的助手操作，不扩展到人工生成区域；文件导出仍需确认。权限可撤销，未知费用或不明提交继续暂停对应动作。
- 停止助手不取消或退款已提交的云端任务；沿原任务身份继续读取结果。模型声明或旧候选不能代替本次已保存输出的完成证据；执行中仍可查看历史及顶部信息弹窗。
