# Pure Tokens Switch 1.0.0

一键配置现在只修改 Switch 明确管理的字段，保留客户端已有的个人设置、嵌套参数和自定义名称，修复 Claude Desktop 等客户端因额外配置被误报冲突的问题。

## 一键配置兼容性

- Claude Desktop 的费用估算开关及其他额外字段不再被误认为供应商归属冲突；检测、重复配置、直连转本地映射和恢复均保留其原值及类型。
- 兼容矩阵中的文件适配器按受管字段合并，不再仅因未知字段名或非受管属性类型拒绝配置。保留数据不等于保证第三方客户端接受任意类型的设置。
- 修复 Claude Code 自定义描述的检测、MiniMax 嵌套能力及默认偏好的保留，以及 DSH 重复应用的字节幂等性。Factory 自定义显示名仍须保留归属前缀，不接管已移除前缀的个人条目。

## 切换模型与恢复

- 重配或换模型时保留有个人定制的旧记录，不将旧模型参数移植到另一个模型。
- 恢复按客户端契约断开受管凭据和默认选择；停用的独立连接移除旧 Key，共享连接保持所需的地址和 Key 同步。Gemini 定制 alias 与 definition 成对保留并停用。
- 真实连接归属、鉴权、协议、路径和并发写入冲突继续阻止危险操作；原字节校验、备份和失败回滚保持不变。

## 使用边界

- 偏好冲突提示引导检查模型过滤器或调整选择，不再要求删除无关个人设置。OpenCode 与 Oh My Pi 隐藏已选模型的过滤器仍需调整。
- OpenMausBot 官方恢复仍不可用；Claude Desktop 私有 Skills 回执校验不放宽。VS Code 配置仍仅写文件，不启动或重启编辑器。
- 保留 0.8.1 的模型广场、用量、充值码充值记录、会员和发票记录能力。一键配置修复不新增 HTTP／IPC 字段；连接模式新增本机设置与诊断 networkMode 字段，不新增 HTTP 路由、错误码、数据库迁移或 Web 修改。

## 应用服务连接

- 登录页与设置页可选择「系统代理／直连」，默认仍使用系统代理。直连只影响 Switch 的 Product API 请求，不修改系统代理或证书，也不控制更新器、工具下载、第三方客户端或 Claude 本地映射。
- 偏好保存在本机设置 schema 5，旧设置默认 system；保存失败保持原模式。切换会刷新匿名服务检测，不自动登录、不重发在途操作；诊断包含所选模式，不包含代理地址。

## 保留的客户端与账户能力

- Claude-3p 支持缺省 bearer 鉴权。Windows Claude Desktop 使用 Local AppData，不写入旧 Roaming 目录；从旧配置升级后重新应用配置，旧目录保留，运行时效果须由实际宿主验证。
- 模型广场保留独立调用示例、概览和价格页签，价格按目录声明展示；使用记录保持历史价格与已结算金额，不以当前价格重算。
- 充值记录打开时刷新一次，滚动到底部续页，保留兑换码充值、会员购买及只读发票记录。在线付款、发票申请和下载仍在 Web 完成；邮件服务接收不等于已送达。
- 客服保留“新用户加群获取 $5”，顶部保留“新用户赠$5”；仅在额度与企业状态符合要求时展示，不自动发放额度。任务中心每页最多 200 项，分类数量按全项目统计。

## 助手与创作边界

- 单个镜头及剧集／画布成片接受 ±1 秒（含边界）容差，范围内不因时长阻塞、不累计镜头容差、不自动重做；画幅、内容与质量核验保留。
- 自动审批仅适用于已声明的助手操作，不扩展到人工生成区域；文件导出仍需确认。权限可撤销，未知费用或不明提交继续暂停对应动作。
- 停止助手不取消或退款已提交的云端任务；沿原任务身份继续读取结果。模型声明或旧候选不能代替本次已保存输出的完成证据；执行中仍可查看历史及顶部信息弹窗。

## 安装与验证

Windows x64 与 macOS Apple Silicon 安装包已通过本次用户验收，核心账户、配置写入与恢复、客户端直连、用量、充值码、状态栏和应用内更新流程已由维护者确认稳定。三平台来自同一冻结提交，更新签名、来源、许可证与安装包完整性均已核验。

macOS Intel 已完成同源码交叉构建和包内容校验，未执行 Intel 原生实机 Smoke。社区包未使用 Apple Developer ID 公证或 Windows Authenticode；Tauri Updater 使用独立签名校验。一般功能验收不代表每个第三方宿主版本或所有付费调用已覆盖。
